# Геометрия МО для карты (шаг 24б)

Сгенерировано `src/24b_geometry.py`. Все числа взяты из расчёта скрипта; параметры — `config.yaml`, группа `step24b_geometry`. Метрики файлов считаны по записанным GeoJSON (после округления координат). Площади в км² не печатаются: изменение площади |ΔS| считается как относительное.

## Исчезнувшие части (крупной считается часть площадью не менее 1e-08 град²)

Часть сопоставляется с итоговой геометрией по расстоянию между центроидами; площадь в м² считается способом шага 0б (равновеликая проекция). Мелкие части, исчезнувшие при упрощении или округлении, нарушением не считаются.
