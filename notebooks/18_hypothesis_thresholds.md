Сгенерировано `src/18_hypothesis_thresholds.py`. Пороги зафиксированы до просмотра результатов гипотез: для переменных гипотез здесь нет наблюдаемых эффектов — только нулевые распределения, число МО с данными и размеры групп. Наблюдаемые эффекты приведены только для контролей.

## Формулы

- H Краскела–Уоллиса с поправкой на связки: H = [12 / (n(n+1)) · Σ R_g² / n_g − 3(n+1)] / [1 − Σ(t³ − t) / (n³ − n)]; k_eff — число непустых типов; η²_H = max(0, (H − k_eff + 1) / (n − k_eff)).
- Спирмен: ρ = коэффициент Пирсона на рангах (средние ранги при связках).
- Нуль: 5000 перестановок меток типов (для ρ — одной из переменных); seed комбинации = 180000 + номер строки в таблице порогов. Порог p95 / p99 — 95-й / 99-й процентиль нуля; для ρ — односторонний в ожидаемом направлении (для «−» — 5-й / 1-й процентиль) и двусторонний по |ρ|.
- Уровень «внутри регионов»: значение заменяется нормированным рангом внутри региона (region_code), (ранг − 0,5) / n_региона; перестановки только внутри регионов; регионы с числом МО с данными < 3 не участвуют (колонка regions_excluded).
- Тип с числом МО с данными < 5 исключается из теста переменной (status); если осталось < 3 типов — «не оценивается».
- Вердикт verdict_kw: «подтверждено», если p_dec = (1 + #{нуль ≥ obs}) / (1 + 5000) < 0.05 и obs_m > p95_m не менее чем в 23 из 24 месяцев.
- Месячные проверки: доли category_shares за месяц m сопоставляются с разбиением месяца m; статичные переменные (market_access, ж/д, Росстат, среднее долей за 2024) — с разбиением каждого месяца. Для канонического декабрьского разбиения доли берутся за 2024-12. Корреляции Г2, Г3 не зависят от разбиения: partition — месяц долей; `mean2024` — обе переменные статичны.
