## Правила

- obs — η²_H на каноническом декабрьском разбиении; p_dec = (1 + #{нуль ≥ obs}) / (1 + 5000) по векторам `hypothesis_null_dec.parquet`; months_ok — число месяцев из 24 с obs_m > p95_m (p95_m из таблицы порогов); confirmed_level = (p_dec < 0.05) и (months_ok ≥ 23); для status не «ok» — пусто.
