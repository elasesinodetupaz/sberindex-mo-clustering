### Выводы (разведочно)

- Канон воспроизводится (ARI = 1.000); при смене seed ARI канона с перезапуском от 0.893 до 0.993, медиана 0.965 (расчёт шага 25, разведочно).
- При clr-кодировках разбиение на 6 типов заметно отличается от канона: ARI от 0.277 до 0.299 (расчёт шага 25, разведочно). Типология описывает структуру в z-score пяти долей и в этом смысле зависит от кодировки.
- Главная ось z-score пяти долей несёт 57% дисперсии; ρ(PC1, rest) = -0.76 (расчёт шага 25, разведочно). Существенная часть различий между МО по пяти долям согласуется с различиями в доле «прочего».
- Медиана rest по типам — от 23.2% до 33.2%; η²_H rest по типам 0.596 (общий уровень), 0.138 внутри регионов (расчёт шага 25, разведочно).
- Г2: знак ρ по долям и по лог-отношению совпадает; на уровне всех МО ρ меняется с +0.117 до +0.015, внутри регионов с -0.301 до -0.332, между регионами с +0.494 до +0.500 (расчёт шага 25, разведочно).
- Г3: знак ρ по долям и по лог-отношению совпадает; на уровне всех МО -0.267 → -0.278, внутри регионов -0.464 → -0.481 (расчёт шага 25, разведочно).
- η²_H по типам при переходе к лог-отношению сильнее всего снижается для категорий Транспорт (0.606 → 0.193) и Здоровье (0.637 → 0.418), меньше всего — для Маркетплейсы (0.661 → 0.658) (расчёт шага 25, разведочно). Различия типов по этим категориям отчасти совпадают с различиями в доле «прочего»; метки типов при этом взяты из канона, а не перестроены.
