## Формулы

- Г6: переход — МО, у которого канонический тип в месяце t отличается от типа в t−1 (t = 2023-02 … 2024-12). S = доля переходов, у которых конечный тип входит в N_NEAREST ближайших к исходному. Ближайшие — по евклидову расстоянию между центроидами (средний z-score 5 долей МО типа, 2024-12, kmeans_labels_final); N_NEAREST = 2 — основной вариант, [1, 3] — чувствительность.
- Нуль Г6: исходный тип перехода сохраняется, конечный выбирается среди типов ≠ исходного с вероятностями, пропорциональными общей частоте конечных типов всех реальных переходов (с нормировкой без исходного). 5000 повторов; seed = SEED_G6 + N_NEAREST. Число попаданий в ближайшие среди n_i переходов из типа i в этом нуле распределено как Binomial(n_i, q_i), q_i — вероятность попасть в ближайшие; так нуль и считается (совпадение с прямыми симуляциями — в проверке ниже). null_mean по исходному типу = q_i.
- **Оговорка Г6:** переходы одного МО зависимы (одно МО даёт несколько переходов), поэтому порог по переходам как по независимым наблюдениям оптимистичен; на шаге 19 будет бутстреп по МО.
- Г9: P_t — доля МО, сменивших канонический тип между t−1 и t. D_{c,t} — медиана по МО (со значением в обоих месяцах) разности сырых долей share_c(t) − share_c(t−1); z_{c,t} = (D_{c,t} − медиана_t) / (1.4826 · MAD_t) по 23 месяцам категории; M_t = max_c |z_{c,t}|. Статистика — ρ Спирмена (P, M), n = 23, ожидаемый знак «+», односторонний порог.
- Нуль Г9: (а) 5000 перестановок месяцев одного ряда (seed SEED_G9); (б) 22 ненулевых циклических сдвига одного ряда относительно другого. **У способа (б) всего 22 значения, его p95 и p99 грубые** (интерполяция между крайними значениями). Управляющий порог — больший из двух p95.
