# Шаг 24f. Данные слоёв лендинга

Описательный шаг: только чтение готовых файлов, новых моделей, тестов и порогов нет. Скрипт `src/24f_layer_data.py`; параметры и ожидаемые значения — группа `step24f_layers` в `config.yaml`.

Входы: `data/geo/mo_national.geojson`, `kmeans_labels_final.parquet`, `types_outside_sample.parquet` (шаг 24c), `types_last_month.parquet` (шаг 24g), `data/raw/market_access.parquet`, `kmeans_k6_trajectories.parquet`, `kmeans_k6_matching.parquet`, `type_portraits.parquet`. Выходы: `layer_data_24f.parquet` (одна строка на МО), `region_coverage_24f.parquet` (одна строка на регион).

## 6. Ограничения

1. Доля месяцев считается относительно канонической метки декабря 2024 (seed 42). Месячные метки в траекториях получены из официального разбиения каждого месяца (минимум inertia из 100 запусков, шаг 12a; для декабря 2024 это seed 66) с последующим сопоставлением с якорем. Метка декабря в траекториях отличается от канонической у 31 МО (ARI 0.9609), поэтому у этих МО `months_same` не больше 23 по построению сравнения.
2. Сопоставление типов между месяцами неуверенное для типа 4: неоднозначно в месяцах 2023-01, 2023-02, 2023-06, 2023-07, 2023-08, 2024-07; умеренно в месяцах 2024-08, 2024-11 (по `kmeans_k6_matching.parquet`; уверенных сопоставлений 15 из 23). У остальных типов неуверенных сопоставлений не больше 2 из 23. У МО типа 4 `stable_share` отражает в том числе качество сопоставления месяцев, а не только смену типа самим МО.
3. `market_access` есть не у всех МО: пусто у 23 (у класса 1 — 0); регионы пропусков: Архангельская область — 1; Иркутская область — 1; Камчатский край — 3; Красноярский край — 4; Мурманская область — 1; Республика Саха (Якутия) — 4; Республика Тыва — 1; Хабаровский край — 3; Чукотский автономный округ — 5. В слоях такие МО нужно показывать как «нет значения».
4. Класс 4 присвоен по месяцу, отличному от декабря 2024 (у 74 МО последний полный месяц — от 2023-03 до 2024-11); тип класса 4 получен по параметрам этого месяца и не входит в статистики шагов 10–28 и в карту 24d. Качество присвоения зависит от согласия метода с месячными метками на выборке (`month_agreement`).
